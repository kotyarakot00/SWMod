Мод для образовательной платформы Uchi.ru.

## ⭐ Функционал

- Может менять базовые параметры
- Может настраивать сайт под ваше удобство
- Сохраняет все настройки в профили

## 🎮 Установка

Открой консоль на сайте Uchi.ru (F12) и вставь:

```fetch("https://raw.githubusercontent.com/kotyarakot00/SWMod/main/mod.js").then(r=>r.text()).then(eval)```

❗Мод может слетать при переходе на следующие страницы на сайте, вам придётся вставлять код в консоль каждый раз.

## ❔ Как пользоваться

После установки в правом нижнем углу появится кнопка SW. Нажми на неё — откроется меню.

## ⚠️ Важно

Все параметры меняются визуально. Мод может слетать при переходах на следующие страницы или при перезагрузке сайта.
